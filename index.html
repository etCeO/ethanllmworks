Where Logic Meets Language

Human design × Machine generation

Prompt Engineering Python Java C++ LLM Systems Web Apps Algorithm Design AI Pipelines

Ethan LLM Works is a self-directed portfolio project that involves taking original programs and transforming them into interactive simulations and computational tools using advanced techniques in prompt engineering. Every project starts with logic developed in Python, Java, or C++, evolving into a full-fledged web application through AI-assisted pipelines.

These projects serve as more than visual redesigns — they are a testament to bridging conventional software development with the latest AI innovation. Although the underlying code and algorithms are original, the web interfaces have been developed through purposeful experimentation with large language models. The goal is not authorship of these websites, but to showcase the application of AI engineering skills in crafting prompts and refining interfaces.

This platform is a part of an independent study into the development of LLM products, prototyping, and computational design — exploring how human-designed logic and machine-assisted generation can be combined to create function-oriented digital systems.
